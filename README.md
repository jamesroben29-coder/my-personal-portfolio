# James Roben — Personal Portfolio

A modern, responsive personal portfolio website built to showcase my skills, education, and frontend development projects.

## 🚀 About This Project

This portfolio presents my journey as a Junior Frontend Developer. It highlights my technical skills, featured projects, and contact information.

## 🛠️ Tech Stack

- React.js
- TypeScript
- Tailwind CSS
- Vite
- Lucide React / React Icons
- Git & GitHub

## ✨ Features

- Responsive design for desktop, tablet, and mobile
- Modern dark-themed user interface
- Smooth navigation between sections
- About Me and Technical Skills sections
- Education information
- Featured project showcase
- GitHub and Live Demo links
- Downloadable CV
- Contact section

## ⚙️ Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd my-personal-portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Build for production

```bash
npm run build
```
